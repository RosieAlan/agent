# 深圳 Agent 开发求职训练计划 V2

生效：2026-10-15。用户要求重新设计：深圳 Agent 开发岗位，月薪底线 15k、目标 15–30k，原课程掌握至少 80%。本版统一替代此前周表与顺序补丁。

## 1. 求职定位与时间

本科、约五年前端经验，熟悉 JS/Vue，后端薄弱。定位为有前端经验、能独立交付 Agent 应用的开发工程师；主投深圳 Agent 应用、Agent 全栈和 TypeScript/Node Agent 岗。前端经验、AI 经验和后端经验按真实情况分别描述。

薪资暂按税前固定月薪理解，投递时核对固定薪资、试用期、发薪月数、绩效和奖金。薪资目标用于职位筛选与训练深度，录用和定薪依据实际能力、履历、具体 JD 与面试。

正式开课2026-10-16，八周复盘检查日2026-12-11。八周、每周五天、每天四至六小时，共 160–240 小时。每周复盘真实耗时与缺口，达标可提前完成。主要技术栈为 TS + Node/NestJS + PostgreSQL/pgvector + LangChain/LangGraph + MCP/Skills，复用 Vue 经验。Python、多模态、框架二开等按具体必投岗位专项验收并明确课时交换。

HTTP/JSON/fetch/组件通信采用简短诊断，按实际卡点补讲。SQL、类型与运行时校验、后端鉴权、事务、异步与异常处理通过 Agent 功能进行实操。

## 2. 双重达标要求

岗位能力：对照 REQUIREMENTS.md 的截图和公开样本，掌握模型接入、Prompt/上下文、结构化输出、工具、记忆、RAG、图编排、多 Agent、数据权限、性能成本、安全、交付和业务表达。每项能解释、独立修改、排错，并说明边界及取舍。

课程能力：第一至二十章拆为 100 个检查点，见 COURSE-COVERAGE.md。总分至少 80/100，每章至少 3/5，核心章至少 4/5；序章、第 2.5 章、终章与四篇面试另行全部安排并验收。

检查点评分：0 待学或未通过；0.5 能闭卷解释并回答新场景；1 达到前项且提交相应任务证据。实现型要求本人改动和运行、失败分支证据；概念型要求独立方案和取舍。这是训练对“掌握 80%”的可核对口径，正式授课时结合原文细分证据。岗位与课程两项同时达标。

周评分：实操40、原理20、排错20、面试20，总分至少80，各维度至少六成。身份隔离、密钥保密、危险动作授权、数据真实性为相关任务必过项。

## 4. 持续演进的项目

项目：业务知识与需求评审 Agent 工作台。已有项目作为需求分析参考与运行案例，学生独立练习隔离到 interview-training/labs/，对应实现开始时才建文件。现有前端优先复用。

最终链路：登录会话 → 上传规范 → 引用问答 → 授权工具查业务数据 → 专家分析 → 评审修订 → 确认导出 → 监控评测 → 部署复现。每块由业务推导输入输出、状态、边界和文件。至少做一次框架外工具循环、一次手写SQL、一次独立模块设计。保留真实贡献与AI帮助范围，个人项目如实标注。

## 5. 每课执行与作业

每块标明训练周天、原章节、岗位项、学习目标。按业务问题→具体输入输出→原理→调用链与设计原因→完整适配代码/目录→验证→作业及标准答案讲授。新概念完整解释，已有经验短诊断。

每日四小时：复习20分钟、讲解与原课程60分钟、实操100分钟、排错40分钟、面试表达20分钟。额外时间优先补练。每课至少两道面试题、一项实操、一项异常定位；必背稿1–3条，全部给标准答案、评分点和追问。提交回答/代码路径/证据/卡点/AI帮助范围。

复习用第1/3/7/14天新场景提问，到课时核对队列。普通练习可查文档和用AI；独立验收明确限制代写，检查解释、临场修改和故障定位。用户说“下一块”继续并保留未完成项。平台标记、讲授、代码实现与独立掌握分别记录。

## 6. 毕业交付与门槛

持续执行（2026-10-16补充）：每次课末、作业批改后和进度查询时，展示PROGRESS.md顶部看板，分别汇报当天任务完成/剩余、八周四十天位置、课程独立验收分数及达标缺口、下步动作。当天任务比例按当日明确目标计数，课程掌握按100检查点及章节门槛评分；时长待学生提供实际记录。每完成一个经验证的小目标或适合保存的阶段，自动提交并普通推送相关讲义、练习和进度，报告提交编号与验证范围，遵循AGENTS.md第16、17条。

1. COURSE-COVERAGE 总分至少80，满足每章与核心门槛；额外七项材料均参与学习考核。
2. 可复现项目：启动、初始化、迁移、浏览器操作、日志、备份恢复、回滚文档与证据。
3. 一次90分钟新需求变更和一次45分钟故障定位，按周评分规则通过。
4. 两次不同题目的45–60分钟模拟面试各至少80分，含定义、项目追问、系统设计、短代码和前端经验迁移。
5. RAG至少30题：20可答、5无资料、5跨用户/恶意；训练门槛为可答题证据命中、答案有依据各至少16/20，跨用户泄露和危险指令执行均0；保存标注、参数和原始结果。
6. 异常覆盖无权限、参数非法、限流/超时、工具失败、取消、循环上限、专家部分失败、重复提交、历史、快照及审批恢复。
7. 至少一次前后方案对比，记录成功率、时延样本、Token和费用，按当时实际供应商计费；缺失项写待测。
8. 三分钟项目介绍、十分钟架构讲解、三个真实故障案例，简历逐条核实。
