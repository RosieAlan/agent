## 已确认的广告核心表

db_amazon_adv_test共142张表，以下4张候选表当前SELECT 1 LIMIT 1均无结果：

| 表 | 关键字段 | 拟用于 |
|---|---|---|
| t_amz_adv_campaigns | campaignId、profileid、name、dailyBudget、campaignType、state | 广告活动与预算信息 |
| t_amz_adv_rpt2_sp_compaigns | campaignId、profileid、bydate、impressions、clicks、cost | SP活动按日报表 |
| t_amz_adv_rpt2_sp_compaigns_attributed | campaignId、bydate、attributedSales1d/7d/14d/30d等 | 明确归因窗口的销售额/转化 |
| t_amz_advert_report | sellerid、marketplaceid、sku、bydate、currency、spend、totalsales等 | 另一套商品广告报表，口径需核对 |

字段compaigns为源表实际拼写，接入时照用。活动日报主键bydate/campaignId，归因表主键campaignId/bydate；正式查询应限定profileid和日期，并核对活动关联与归因口径。SP三表尚缺币种/时区及店铺映射核对，不能将不同窗口或币种任意混用。

kaidu_test共774张表，按广告/活动命名筛到video_advertising_effect，当前同样无记录；包含report_date、ASIN/SKU、观看/点击字段，尚不足以提供完整花费与归因销售额分析。

## 后续接法

外部测试库只提供业务数据的只读连接；新项目会话、任务、方案、审批、执行模拟及评测记录使用项目自有库。源库root账号具有广泛权限，当前依靠程序只读事务收窄本次操作，后续正式接入应使用由管理员提供的只读账号。模型调用通过明确工具执行参数化查询，初步查询范围限制店铺/日期/返回条数。
