# 第六章面试题与参考答案

本文件随 6.1～6.6 的学习进度持续补充。题目围绕真实业务场景、协议设计、状态机取舍、Structured Output、前端组件映射和流式架构展开。

## 6.1 纯文本回复的天花板

### 问题 1：Markdown 报告末尾有三个分析方向，如何改成可点击卡片？为什么需要稳定 ID？

参考答案：后端返回 `AIUIResponse`，在 `components` 中放一个 `selection`，每个选项包含稳定的 `id`、显示文字和说明。前端根据 `type` 渲染卡片，点击后回传 `UIAction` 中的 `selectedId`。稳定 ID 能让后端直接定位业务分支；显示文案可以调整，流程判断仍保持一致。例如点击“完整性检查”回传 `completeness_check`。

### 问题 2：选择类型、填写表单、确认提交、生成结果，哪些由模型决定，哪些由状态机控制？

参考答案：模型负责理解开放输入并推荐合适的组件；状态机控制选择、表单、确认等关键步骤。用户操作已经是结构化数据，状态机能准确校验当前阶段并推进下一步，避免模型对同一操作产生不同解释。例如 `select functional` 进入 `fill_detail`，确认取消时返回表单。

### 问题 3：符合 Zod Schema 的 card 为什么仍可能展示虚构负责人和工期？

参考答案：Schema 校验字段结构和数据类型，负责人、状态、工期等事实需要可信数据源。服务端应先根据用户权限查询数据库或业务接口，再把事实传给模型组织表达，并对输出做业务校验。例如需求负责人从 `requirements` 记录读取，页面卡片只能使用查询结果。

## 6.2 UI 响应协议与 Structured Output

### 问题 1：模型返回的 selection 选项使用了 value，前端协议要求 id。请求会在哪一层失败？怎样定位？

参考答案：服务端的 Zod 校验会在 `components[0].options[0].id` 报缺失，前端不会收到可渲染的合法协议。先核对模型原始输出与 `ui-schemas.ts`，再调整组件字段指引或输出约束，并重新调用真实模型验证。`id` 是后端状态机识别选项的稳定标识。

### 问题 2：为什么通过 withStructuredOutput 的回复仍需要可信数据源？

参考答案：Structured Output 负责输出形状，业务事实由数据库或可信服务提供。需求详情卡片的负责人、状态和工期应先按用户权限查询，再组织为 UI 组件；服务端还要校验模型返回值与查询结果一致。

## 6.3 完整交互闭环

### 问题 1：用户重复点击旧的“功能需求”卡片，后端怎样处理？

参考答案：后端先读取当前 `sessionStage`。只有 `select_type` 阶段接受 `selection/select`；进入 `fill_detail` 后，同样的操作应被拒绝。前端禁用旧组件可改善体验，后端阶段校验负责最终约束；提交类操作还可增加幂等键。

### 问题 2：两台 NestJS 实例使用 Map 保存相同 sessionId，会出现什么现象？

参考答案：每台实例各有一份内存状态，请求落到不同实例时可能读到不同阶段。生产环境应将阶段和已收集数据写入共享存储，并在推进状态时处理并发更新。

## 6.4 前端组件渲染层

### 问题 1：后端新增 type 为 chart 的组件，旧前端收到后怎样保持页面可用？

参考答案：`ComponentRenderer` 的默认分支显示未知组件提示，其余已知组件继续渲染。应用可同时记录未知 `type` 和协议版本，以便定位前后端发布差异。

### 问题 2：为什么 SelectionCard 只调用 onAction，由 AIChatContainer 统一发送请求？

参考答案：组件负责收集选择并构造 `UIAction`，容器统一管理 `sessionId`、请求状态、错误和消息列表。新增组件时遵守相同回调协议，就能复用容器的请求流程。

## 6.5 工程化与流式适配

### 问题 1：为什么文字适合逐段推送，而表单适合整包下发？

参考答案：文字片段可以追加显示；表单需要完整字段、选项和校验规则后才能正确交互。流式协议可分别发送 `markdown` 增量事件和完整的 `ui` 事件，进度另用 `progress` 事件表示实际执行阶段。

### 问题 2：一个 card 通过 Zod 校验，却显示了虚构的“已完成分析”状态，如何防止？

参考答案：从可信业务记录读取真实状态，生成后再校验 card 字段与业务记录一致。进度事件应由实际执行节点产生；任务仍在等待分析时，UI 显示“待分析”或当前阶段。
